# SPOONFUL RECIPES APP
## Made in MERN Stack (MongoDB, ExpressJS, ReactJSVite, NodeJS)

This project is a recipe-sharing platform where users can share both unique and common recipes. Users can also save their favorite recipes to revisit later. To share a recipe or save favorites, users need to first create an account and log in. While the concept of the site is simple, I truly enjoyed the learning process throughout its development. If you'd like to explore the project, feel free to visit: Spoonful Recipes(https://spoonful-recipes.vercel.app/)

(This project has been a significant challenge for me, as it combines the skills I’ve learned in MongoDB, ExpressJS, and NodeJS. I started building it after learning ReactJS. However, I paused working on it when an employer asked me to complete an assessment project for a job I had applied for. In the midst of that, I lost track of this project.

Recently, while browsing through my GitHub, I came across the unfinished project and decided to pick it up again. I set out to challenge myself to complete it, and I’m really happy that I finally finished it!)
